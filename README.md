# Birthday Wish

Next.js 15 (App Router) + Tailwind + Supabase (Auth, Postgres, Storage).

## Project structure

```
supabase/schema.sql              tables, RLS, column grants, RPCs, storage buckets, seed songs
public/songs/                    built-in song files (referenced by the songs table)
src/middleware.ts                guards /dashboard and /admin ONLY (never /wish)
src/lib/
  time.ts                        timezone-safe birthday/countdown maths
  upload.ts                      file validation, image compression, storage upload
  supabase/{client,server,public,admin}.ts
src/app/
  page.tsx                       landing
  login/                         email + Google
  auth/{callback,signout}/       OAuth code exchange, sign out
  dashboard/                     list, new, [id]/edit  (creator, RLS-protected)
  wish/[slug]/                   PUBLIC page (server component + OG metadata)
  api/view/route.ts              view counter
  admin/                         stats, charts, users, server actions (service role)
src/components/
  WishForm, WishCard, ShareButtons, AppHeader
  wish/{WishView,Countdown,Celebration,Bunting}
  admin/{BarChart,ConfirmButton}
```

## Setup

1. **Install**: `npm install`
2. **Supabase project**: create one at supabase.com.
3. **Schema**: SQL Editor > paste all of `supabase/schema.sql` > Run (run once).
4. **Env vars**: copy `.env.example` to `.env.local` and fill in
   - `NEXT_PUBLIC_SUPABASE_URL`, `NEXT_PUBLIC_SUPABASE_ANON_KEY`: Project Settings > API
   - `SUPABASE_SERVICE_ROLE_KEY`: same page. Server only, never commit or expose it.
   - `NEXT_PUBLIC_SITE_URL`: `http://localhost:3000` locally, your real domain in production
5. **Auth settings** (Authentication > URL Configuration):
   - Site URL: your `NEXT_PUBLIC_SITE_URL`
   - Redirect URLs: add `http://localhost:3000/auth/callback` and `https://YOUR-DOMAIN/auth/callback`
6. **Google login**: Google Cloud Console > APIs & Services > Credentials > OAuth client (Web).
   Authorized redirect URI: `https://YOUR-PROJECT.supabase.co/auth/v1/callback`.
   Then Supabase > Authentication > Providers > Google: paste the client ID and secret, enable.
   (For quick testing, you can turn off "Confirm email" under Providers > Email.)
7. **Songs**: add `.mp3` files to `public/songs/` matching the seed rows (or edit the `songs` table).
8. **Run**: `npm run dev`, open http://localhost:3000, sign up.
9. **Make yourself admin** (SQL Editor):
   `update public.profiles set role = 'admin' where email = 'you@example.com';`
   An "Admin" link then appears in the header.
10. **Deploy** (Vercel): import the repo, add the 4 env vars, deploy, then update the Supabase
    Site URL / redirect URLs to the production domain.

## How the requirements are met

- **Unguessable links**: `slug` defaults to 16 random hex chars (64 bits) generated by Postgres.
- **Public reads only via slug**: anonymous users have *no* table access. The public page calls
  `get_public_wish(slug)` (SECURITY DEFINER). It returns only today's photo/message, so future
  surprises are never sent to the recipient's browser.
- **Creators can't tamper**: RLS limits rows to the owner; column-level grants block edits to
  `slug`, `is_disabled`, `view_count`.
- **Admin**: `is_admin()` policies on every table, plus a service-role client used only in
  server code after re-checking the caller's role. Blocked users' links stop resolving and they
  can't write.
- **Timezones**: each wish stores the recipient's IANA timezone. The server computes "today" with
  `now() at time zone <tz>`; the client countdown targets that zone's local midnight (DST-safe).
  When midnight passes while the page is open, the client calls `router.refresh()` to load the
  new day's content without a reload (music keeps playing).
- **Fallback**: no `wish_days` row for today means default photo/message.
- **Storage**: `wish-images` (5 MB; jpeg/png/webp) and `wish-audio` (10 MB; common audio types).
  Limits are enforced by the bucket itself, plus client-side checks. Writes only into
  `<bucket>/<your user id>/`. Photos are downscaled to 1400px in the browser before upload.
- **WhatsApp previews**: `generateMetadata` sets `og:title` and `og:image` (the default photo).
  The page is `noindex`. Crawlers don't run JS, so they never inflate view counts.

## Notes and limits

- Scheduled days are for specific calendar dates (e.g. 2026-12-15). Next year, add new dates;
  the default photo/message keep working in between.
- Deleting a wish doesn't delete its files from Storage. Add a cleanup job if storage grows.
- The admin page loads all users and links; add pagination for very large datasets.
- Uploaded music is the creator's responsibility. Consider a copyright notice in your terms.
